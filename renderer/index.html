Checkable Renderer

Paste any checkable.json (or receipts.json alias) URL below and see it turned into a readable page, live, right here. Nothing is uploaded — this fetches the manifest directly in your browser and renders it client-side. If it doesn't parse or is missing required fields, you'll see an honest error, not a blank box.

Embed this on your own site

Adopted the standard? Don't make visitors read raw JSON — render it. One script tag, no build step, no framework required.
<div id="receipts"></div>
<script src="https://checkable.clickcoded.com/renderer/render.js"></script>
<script>renderReceipts('receipts', 'https://yourdomain.com/receipts.json');</script>

That's the same script this page uses. Read-only — it never modifies your manifest or sends it anywhere but the browser rendering it. Full source: render.js.
